# Avatar System

- Separate avatar appearance from account and conversation data.
- Support configurable skin tone, eyes, hairstyle, facial features, and clothing.
- Represent appearance using validated, versioned configuration objects.
- Use stable identifiers for reusable assets.
- Persist and restore each user's avatar configuration.
- Keep rendering responsive across web and mobile.
- Start with a practical layered 2D avatar.
- Keep AI-generated images and video generation optional and modular.
- Validate uploaded files and restrict file types and sizes.
- Test configuration validation, persistence, and ownership.
